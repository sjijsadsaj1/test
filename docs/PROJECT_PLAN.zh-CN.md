## 3. 当前有效算法

当前主要实验模式是 `grounded_delta`，流程为：

1. ApexNav根据真实观测更新地图，生成可达的frontier（可探索边界）及A*路径前缀。
2. 在真实语义分数接近、属于中间分数段且观测不足的候选上调用AVIC。
3. 绑定同一步当前图像、机器人姿态和真实路径前缀。最多6个动作；尚未分叉或不足两步的候选提前跳过。
4. Qwen选择预测长度，但不能截断到候选分叉之前；SVC生成未来视图并采样多帧。
5. Qwen分别评价结构一致性、真实上下文支持和新增信息；BLIP比较预测视图与同一真实图像的分数。
6. 合格增量作为一次决策的临时正奖励，交给原版Hybrid规则；以ROS日志确认目标、路径和动作是否改变。
7. 若实际切换了目标，同步评估模式短期保持该目标最多6个动作（含首次动作），每步闭环重算安全路径；
   不复用奖励、不锁死动作序列，发现目标、受阻或边界失效即交回普通规划。保持期间不发起新的AVIC查询。
8. 到达未确认的搜索点，不立即报告找到目标；进行有界真实观察。确认成功则切回原有高置信目标导航，
   失败则暂时排除该点并重规划；若确实没有可探索/可达目标，仍可能按原版NO_FRONTIER终止。

当前奖励公式：

```text
delta = Q25(预测帧BLIP分数) - 当前真实图像BLIP分数
bonus = min(0.06, 0.75 × reliability × delta)  # 仅全部审核条件通过时
决策分数 = 完整的真实frontier地图分数 + bonus
```

通过条件包括真实上下文支持、非想象独有目标、可靠性≥0.55、至少两个合法支持帧、
Q25增益≥0.01且至少两帧各提升≥0.01。结构可信但没有可见性收益仍为零奖励。
该评分衡量预测视角的潜在价值，不证明生成物体真实存在。

| 配置 | 当前主要实验取值 |
|---|---|
| score mode | `grounded_delta` |
| route contract | `current_pose_astar_prefix_v1_20260915` |
| score contract | `grounded_view_delta_v2_20260915` |
| 实分数/预测权重参数 | 0.25 / 0.75；只用于归一化预测增量，真实地图分数不乘0.25 |
| 最大临时奖励 | 0.06 |
| G1分数段 / Top-2最大分差 | `[0.191149, 0.227590]` / 0.01 |
| 预热 / 单任务调用上限 / 冷却 | 26步 / 20次 / 5步 |
| 停滞恢复 | 关闭：`APEXNAV_STAGNATION_RECOVERY=false` |
| AVIC目标保持 | 最多6动作；`APEXNAV_AVIC_ROUTE_COMMIT_STEPS=0`可关闭作诊断；不是Qwen所选预测长度 |
| 未确认搜索点确认 | `APEXNAV_TARGET_CONFIRMATION=true`；每次4转向、每任务最多3次；失败点0.75m范围排除30步；false回退旧行为 |

`strict_evidence` 保留历史锚点、短探测和新增证据审核，用于历史策略复测。
通用启动器默认仍是严格评分；当前100任务脚本显式选择新模式。

想象结果不写入真实地图；同目标的无效重规划会回滚。09-19改进版开始修改**未确认搜索点的STOP策略**，
不修改Habitat成功判定或已确认目标的普通到达条件；官方Apexnav_1不加入该修改。

## 5. 当前问题

1. **正奖励可信度仍存在矛盾。**最新10个正奖励候选中，5个的文字说明提到虚构物体或场景不一致，
   却仍给出0.8可靠性并通过；相关干预需人工对照预测与真实画面，不能仅依赖数字阈值。
2. **预测视角增益不等于导航收益。**发生实际动作变化的3条失败任务中，2条终点更远、1条更近；均未成功。
3. **短预测与整条探索方向之间缺少验证。**例如 `zsNo4HB9uLZ:40` 仅两次右转的预测获得奖励，
   随后切换frontier；需要验证这种局部观察是否足以支持方向选择。
4. **有效支持稀少。**302个候选中256个因缺乏真实目标上下文或想象独有目标而拒绝；这些是模型判断，
   尚不能一概视为正确拒绝，也不能直接取消条件。
5. **残余工程限制。**当前未做全面RGB/深度质量筛选；路径前缀最多6步；原版epsilon比较器仍有已知排序风险；
   感知服务偶有读取超时。处理任何一项都需记录对实验可比性的影响。
6. **选择与执行的持续性。**审计发现Tb162在step112换目标后，step113已回退；oLB116 step260→261也发生回退。
   已补上有界目标保持，但这不保证预测动作逐个重现；当前score消息不包含Qwen所选长度，
   暂用真实路线前缀长度与6动作上限，不宣称已经实现严格的预测/执行时域对齐。
7. **搜索点与任务目标混淆。**超深度/疑似/极限搜索原先与高置信目标共用到达STOP条件。
   09-19已加入有界确认，待同一50任务验证救回与损失；高置信误检本身及无WM时的路线差异尚未解决。

## 8. 文档维护约定

- **计划书**更新当前状态、进展及待办；完成的计划转为进展，并链接修改日志。
